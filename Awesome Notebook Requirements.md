# Awesome Notebook Assignment Requirements

In this assignment, you will create a stand-alone example that showcases one of the methods we learned about in class. This could use a high-level library (for example, Hugging Face) to demonstrate inference from pre-trained weights, or implement a lower-level aspect of one of the algorithms. These examples will be shared with the class. Your goal is to help someone improve their understanding of the method.

## Requirements

1. Include a text block at the top that provides a summary of the contents of the notebook. This block should also include:
   - A link to the paper from which the idea originates
   - Your name
2. Give the notebook file a descriptive name. For example, a notebook about masked autoencoders might be called `masked_autoencoder.ipynb`.
3. For full credit, meet with a TA and demonstrate your notebook. It should be clear that you understand how the various elements of the code work and that you can engage in an active discussion about the notebook.
4. Show a few examples of applying the method to example images. These can be your personal images or images from Wikimedia Commons.
5. Ensure the notebook runs end-to-end with minimal user intervention (unless user input is essential, e.g., entering a text prompt).
6. Include all necessary installation commands at the top so that it can run automatically in Google Colab.
7. Comment on whether the method appears to be working well or not—be as detailed as you can.
8. Add visualizations of relevant aspects of the algorithm where possible.
9. If you start from an existing notebook or Python code, clearly reference the source and include a list of the changes you made.
